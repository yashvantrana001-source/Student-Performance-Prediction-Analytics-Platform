# 🎓 Student Performance Prediction System

End-to-end ML web app that predicts whether a student will **Pass** or **Fail**
from attendance, internal marks, study hours, previous performance and assignment score.
Built with **Python**, **Scikit-learn** and **Streamlit**.

## Project structure
```
student-performance-prediction/
├── data/raw/student_performance.csv   # dataset (5,000 records)
├── models/best_model.pkl              # saved sklearn Pipeline
├── models/metrics.json                # metrics used by the app
├── notebooks/                         # EDA notebooks (optional)
├── reports/model_results.csv          # model comparison
├── src/generate_data.py               # creates the dataset
├── src/train.py                       # trains + saves best model
├── app.py                             # Streamlit app (6 pages)
└── requirements.txt
```

## Setup
```bash
python -m venv .venv
# Windows: .venv\Scripts\activate    |  macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
```

## Run
```bash
python src/generate_data.py   # (optional) regenerate dataset
python src/train.py           # train & save the model
streamlit run app.py          # open http://localhost:8501
```

## Google and GitHub sign-in (optional)
Create an OAuth client in [Google Cloud Console](https://console.cloud.google.com/) and/or an OAuth App in [GitHub Developer Settings](https://github.com/settings/developers). Set each provider's callback/redirect URL to the exact app URL, normally `http://localhost:8501` for local development. For a deployed app, use its public HTTPS URL.

Add the credentials to `.streamlit/secrets.toml` (create the folder and file if needed):

```toml
GOOGLE_CLIENT_ID = "your-google-client-id"
GOOGLE_CLIENT_SECRET = "your-google-client-secret"
GITHUB_CLIENT_ID = "your-github-client-id"
GITHUB_CLIENT_SECRET = "your-github-client-secret"
OAUTH_REDIRECT_URI = "http://localhost:8501"
```

Only configure credentials for providers you use. Never commit real OAuth secrets; `.streamlit/secrets.toml` and `.env` are ignored by Git. The app also accepts these values as environment variables. OAuth users sign in with the student role; demo username/password sign-in remains available.

## ML workflow
1. Load CSV, drop duplicates
2. Train/test split (80/20, stratified)
3. Pipeline: `SimpleImputer(mean)` → `StandardScaler` → model
4. Compare Logistic Regression vs Decision Tree
5. Save best model with `joblib`
